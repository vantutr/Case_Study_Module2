# Social Network App
Ứng dụng mạng xã hội console-based viết bằng Java.

## Chức năng
- Đăng ký, đăng nhập, quên mật khẩu.
- Quản lý hồ sơ, kết bạn, đăng bài, nhắn tin, thông báo.

## Cấu trúc
- `model`: Lưu trữ dữ liệu.
- `service`: Logic nghiệp vụ.
- `controller`: Điều khiển luồng.
- `view`: Giao diện console.
